Fjern CLI-hurtigbufferkatalogen.

```bash
archgate clean
```

Fjerner `~/.archgate/`, som lagrer CLI-ens konfigurasjon, hurtigbuffer og (for binærinstallasjoner) den nedlastede `archgate`-kjørbare filen. Trygt å kjøre når som helst -- katalogen gjenskapes automatisk ved behov.

Hvis den kjørende binærfilen ble installert til `~/.archgate/bin/`, beholder `clean` denne `bin/`-katalogen slik at den ikke sletter den kjørbare filen den for øyeblikket kjører som, og fjerner alt annet. Hvis `~/.archgate/` ikke finnes, skriver den ut `Nothing to clean.` og avslutter uten feil.

## Eksempel

```bash
archgate clean
```

```
/home/user/.archgate cleaned up
```

Når den kjørende binærfilen ligger under `~/.archgate/bin/`, merker meldingen at `bin/` ble beholdt:

```
/home/user/.archgate cleaned up (bin/ preserved)
```
