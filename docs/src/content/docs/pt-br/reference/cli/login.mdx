Entre na plataforma Archgate. É o login que concede acesso aos plugins de editor.

```bash
archgate login
```

Inicia um OAuth 2.0 Device Authorization Grant (RFC 8628) na plataforma Archgate. A CLI abre seu navegador em uma URL que já contém o código de uso único e copia esse código para a área de transferência, caso a página o solicite. A URL e o código também são exibidos, então você pode concluir em outra máquina ou colá-los manualmente.

Nenhuma das duas etapas é obrigatória. Em CI, via SSH ou em uma máquina Linux nativa sem servidor gráfico (o WSL alcança a área de trabalho do Windows), a CLI pula ambas e apenas os exibe. Após a autorização, a CLI entrega os tokens ao git via `git credential approve`, então onde eles ficam depende do credential helper que você tem configurado. Um helper apoiado no gerenciador de credenciais do sistema operacional (macOS Keychain, Windows Credential Manager, libsecret no Linux) os mantém criptografados; o helper `store` embutido do git os grava em `~/.git-credentials` em texto puro. Verifique o seu com `git config --global credential.helper`.

Os tokens de acesso têm vida curta. A CLI mantém um refresh token junto deles e renova o token de acesso automaticamente, então normalmente basta entrar uma vez. Se o próprio refresh token expirar ou for revogado, a CLI informa que a sessão expirou, e o `archgate login` a restabelece. Um token emitido antes deste fluxo existir continua funcionando apenas até você entrar na plataforma; a partir daí, somente a sessão da plataforma decide.

Entrar também registra `archgate credential` como um credential helper do git para `plugins.archgate.dev`, que é o que permite ao `git clone` de um repositório de plugin autenticar sem solicitar credenciais. Veja [`archgate credential`](/reference/cli/credential/).

As credenciais são necessárias para instalar plugins de editor via `archgate init --install-plugin`. A CLI em si (check, init, etc.) funciona sem login.

:::tip[Plugin em beta]
Os plugins de editor estão atualmente em beta. Execute `archgate login` para entrar.
:::

## Subcomandos

| Subcomando               | Descrição                                |
| ------------------------ | ---------------------------------------- |
| `archgate login`         | Autenticar (pula se já estiver logado)   |
| `archgate login status`  | Mostrar o status atual de autenticação   |
| `archgate login logout`  | Remover credenciais armazenadas          |
| `archgate login refresh` | Entrar novamente, substituindo os tokens |

## Exemplos

Fazer login pela primeira vez:

```bash
archgate login
```

```
By signing in, you agree to the Archgate Terms of Service:
https://archgate.dev/terms-of-service

Opened https://auth.archgate.dev/device?user_code=HZML-HXLB in your browser.
If it asks for a code, enter: HZML-HXLB (copied to your clipboard)

Waiting for authorization...
info: Authenticated as yourname. Plugin access is now available.
Run `archgate init` to set up a project with the archgate plugin.
```

Se o projeto já possuir `.archgate/adrs/`, a última linha exibe:

```
Run `archgate check` to validate your project against its ADRs.
```

## Solução de problemas

### Erros de TLS/proxy corporativo

Se `archgate login` falhar com um erro de certificado TLS (comum em redes com proxy corporativo), aponte o runtime para o certificado CA da sua organização usando a variável de ambiente `NODE_EXTRA_CA_CERTS`.

No macOS/Linux:

```bash
export NODE_EXTRA_CA_CERTS=/caminho/para/seu-ca-corporativo.pem
archgate login
```

No Windows (PowerShell):

```powershell
$env:NODE_EXTRA_CA_CERTS = "C:\caminho\para\seu-ca-corporativo.pem"
archgate login
```

No Windows (cmd):

```cmd
set NODE_EXTRA_CA_CERTS=C:\caminho\para\seu-ca-corporativo.pem
archgate login
```

No Windows (Git Bash):

```bash
export NODE_EXTRA_CA_CERTS=/c/caminho/para/seu-ca-corporativo.pem
archgate login
```

Consulte sua equipe de TI para obter o caminho correto do certificado caso tenha dúvidas.

Verificar o status do login:

```bash
archgate login status
```

```
Logged in as yourname.
```

Fazer logout:

```bash
archgate login logout
```

Reautenticar:

```bash
archgate login refresh
```
